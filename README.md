# SBESM — Simple But Easy Synchronization Manager

A conservative, one-way file synchronization and integrity-checking CLI for
multiple computers, disks and partitions. See `sbesm_technical_specification.md`
for the full design.

## Install

```bash
python3 -m venv .venv
.venv/bin/pip install -e .
```

## Usage

```bash
sbesm --help
```
